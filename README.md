# api-deprecation-gateway-python

FastAPI 之上的一层 **API 版本协商与弃用生命周期管理** 中间件。

- 四种版本来源（路径 > 请求头 > 查询参数 > 媒体类型参数），冲突按固定优先级
  唯一裁决，无法判定时返回可区分错误，绝不猜测版本。
- 完整生命周期（可用 / 已弃用 / 计划下线 / 已下线）与元数据在加载期强校验，
  矛盾配置、过短弃用窗口一律拒绝。
- 已弃用版本响应带标准 `Deprecation` / `Sunset` / `Link` 头，响应体保持不变；
  已下线版本一律 `410` 并给出去向指引。
- 策略运行期原子热更新，请求始终读到自洽快照，失败重载不影响生效策略，
  慢请求不阻塞重载。
- 可注入时钟、确定性决策、边界时刻闭区间语义；时钟回拨不会让已下线版本复活。
- 按版本/状态统计调用量，识别仍停留在已弃用版本的流量。

详细说明见 [`docs/version-negotiation.md`](docs/version-negotiation.md)。

## 运行

```bash
uv run python main.py      # 启动演示应用
uv run pytest -q           # 73 项自动化测试
```

`GET /` 仍返回原始的 `{"Hello": "World"}`，行为未变。
